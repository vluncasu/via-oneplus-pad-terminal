# Contributing to VIA

Keep mechanical models, print exports and English documentation consistent. Preserve the part IDs and quantity labels in filenames. Update the BOM and relevant guide when a component changes.

Use FreeCAD or a solid CAD application for mechanical edits. Export the changed component as STEP and STL, then check its mating surfaces and slicer orientation. Keep the cable duct, LED seating and tablet service path clear.

The hardware delivery contains native CAD, STEP, STL, Blender scenes, illustrations and practical documentation. Keep construction macros, internal processing data and local build logs outside the public hardware package.

For Android changes, build and test both applications with the Gradle tasks described in the software guide. Check Bluetooth, camera permissions and Back behavior on the actual devices before claiming device interoperability.

State physical test results separately from CAD checks. Inspect document links and final PDF pages before publishing updated instructions.
